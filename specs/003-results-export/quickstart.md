# Quickstart: 搶答結果與匯出

**Feature**: `003-results-export` | 驗證本功能是否完成的操作手冊。實作細節見 `tasks.md`。

## 前置條件

- 001、002 已完成；`npm install` 完成
- Google 連線已依 [001 quickstart](../001-guided-notes-import/quickstart.md) 設定好，老師帳號已連結
- 老師雲端硬碟中的題組範本副本（可編輯）；另準備一份只有檢視權限的試算表

## 自動化測試

```bash
npm test -w packages/server -- writeback csv record results
```

不需要網路與憑證。包含：版面檢查、備份名稱、`composeCellText`、失敗時不寫入、`RAW` 與範圍跳脫、CSV 跳脫與公式前綴、紀錄檔原子寫入與還原、學生結果在活動結束前不含 rankings（research R8）。

## 手動驗證情境

啟動 `npm run dev`，用題組範本的副本建立 3 組的活動，跑完 4 題（第 3 題無人搶答，第 4 題某組答案輸入 `=1+1`）。

| # | 操作 | 預期結果 | 對應 |
| --- | --- | --- | --- |
| 1 | 第 2 題結束時看學生分頁 | 1 秒內出現第 2 題成功組別與答案，看不到其他組答案 | AC-05、AC-04 |
| 2 | 活動結束後看學生分頁 | 自動出現完整結果；本組列醒目標示；第 3 題「無人搶答」 | AC-01、AC-02、REQ-EXP-13 |
| 3 | 老師結果頁 | 每題完整順位、各組成功題數 | AC-03 |
| 4 | 活動進行中按寫回 | 被拒絕，說明要先結束 | AC-10 |
| 5 | 活動結束後按「寫回 Google Sheets」並確認 | 顯示寫入格數、備份工作表名稱與連結 | AC-06、AC-13 |
| 6 | 打開該試算表 | 題組填空格為「（1）答案」；第 3 題只剩標記；`=1+1` 顯示為文字；多了一個「學習單-備份-日期時間」工作表，內容與寫回前相同 | AC-07、AC-08、AC-11、SC-008 |
| 7 | 用版本記錄比對寫回前後的學習單工作表 | 只有填空格不同 | AC-09、SC-002 |
| 8 | 在試算表第 3 列上方插入一列後再寫回 | 被拒絕並指出對不上的題號；沒有新增備份、沒有格子被改 | AC-12、SC-007 |
| 9 | 解除 Google 連結後寫回；再改用只能檢視的試算表跑一輪後寫回 | 分別提示重新連結、沒有編輯權限；試算表沒有被改動 | AC-14 |
| 10 | 寫回時關掉網路 | 15 秒內顯示連線失敗；恢復網路後重試成功，結果與寫一次相同 | AC-15 |
| 11 | 匯出 CSV，分別用 Excel 與 Google Sheets 開啟 | 中文正常；7 個欄位；`=1+1` 前有 `'` | AC-17～19 |
| 12 | 新一輪跑到第 2 題結束後，在終端機按 Ctrl+C，再 `npm run dev` | 老師頁面看得到第 1、2 題結果，可寫回與匯出 CSV | AC-16、SC-006 |

手動驗證結果記到 `specs/003-results-export/manual-verification.md`（原則 VIII）。
