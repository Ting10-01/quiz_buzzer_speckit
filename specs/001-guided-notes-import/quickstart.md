# Quickstart: Guided Notes 匯入

**Feature**: `001-guided-notes-import` | 驗證本功能是否完成的操作手冊。實作細節見 `tasks.md`。

## 前置條件

- Node.js 24 LTS、npm 10 以上；專案根目錄執行過 `npm install`
- Google Cloud 專案已啟用 Google Sheets API、Google Drive API、Google Picker API，建立了 OAuth 用戶端（網頁應用程式，回呼網址 `http://localhost:3000/api/google/callback`）與限制過的 API 金鑰，OAuth 同意畫面的測試使用者包含要登入的老師帳號。步驟見 README。
- 在專案根目錄的 `.env` 自行填入 [google-auth-http.md](./contracts/google-auth-http.md) 列出的四個變數（不要貼到任何文件或對話中）
- 老師帳號的雲端硬碟中有：
  - 單題範本的副本（6 題）、題組範本的副本（4 題，其中 2 個題組）
  - 變形試算表：表頭在第 7 列且題號在 D 欄、表頭寫「編號／答案」、表頭寫「No.／學生填寫」（用來驗證找不到表頭的錯誤）、G9 已填「（2）堆疊」、題號 1、2、4、題號重複
  - 一份只有檢視權限的試算表（由另一個帳號共用過來）

## 自動化測試

```bash
npm test -w packages/server -- import google spreadsheet
```

不需要網路與憑證，應全部通過，涵蓋每個 User Story 的正常與邊界案例（原則 VIII，見 research R10）。

## 手動驗證情境

啟動 `npm run dev`，瀏覽器開 `http://localhost:3000`，選「我是老師」進入匯入頁。

| # | 操作 | 預期結果 | 對應 |
| --- | --- | --- | --- |
| 1 | 未連結時進入匯入頁，按「連結 Google 帳號」並同意 | 回到匯入頁，顯示已連結的帳號 | AC-05 |
| 2 | 再做一次連結，但在 Google 畫面按取消 | 顯示尚未授權，可重新連結 | AC-06 |
| 3 | 在選擇器挑選單題範本 | 預覽「共 6 題」，題號 1–6，每題一個填空格 | AC-01、SC-001 |
| 4 | 挑選題組範本 | 「共 4 題，其中 2 個題組」，第 1 題小題（1）（2） | AC-08、SC-001 |
| 5 | 挑選表頭在第 7 列、題號在 D 欄的試算表 | 正確辨識，位置跟著改變 | AC-03、SC-002 |
| 6 | 挑選表頭寫「編號／答案」的試算表 | 自動辨識，預覽顯示找到的表頭文字 | AC-19 |
| 7 | 挑選表頭寫「No.／學生填寫」的試算表 | 拒絕匯入，列出題號欄、作答欄、題目欄各接受的寫法與修正方式；既有題目清單不變 | AC-15 |
| 8 | 挑選 G9 已填「（2）堆疊」的試算表 | 預覽出現 G9 的舊答案警告，仍可確認匯入 | AC-17 |
| 9 | 挑選題號 1、2、4 的試算表 | 「共 3 題」，列出 1、2、4 | AC-20 |
| 10 | 挑選題號重複的試算表 | 錯誤訊息指出重複的題號與列 | AC-16 |
| 11 | 挑選只有檢視權限的試算表 | 預覽照常出現，另有「無法寫回答案」警告 | AC-13 |
| 12 | 開啟選擇器後直接關閉 | 匯入頁維持原狀 | AC-12 |
| 13 | 關掉網路後挑選試算表 | 15 秒內顯示連線失敗，可重試 | AC-14 |
| 14 | 已確認一份題目後，再匯入錯誤的試算表然後取消 | 原本的題目清單不變 | AC-18 |
| 15 | 重新啟動系統後進入匯入頁 | 仍顯示已連結的帳號，不需要重新登入 | Edge Cases |
| 16 | 按「解除連結」 | 顯示未連結；`credentials/google-token.json` 已刪除 | REQ-IMP-02 |
| 17 | 在 repo 與 log 中搜尋 token 與用戶端密鑰 | 找不到 | SC-006 |

手動驗證完成後，把結果記到 `specs/001-guided-notes-import/manual-verification.md`（原則 VIII：留下驗證紀錄）。
