# Quickstart: 結果與寫回

**Feature**: `006-results-export` | 驗證 006 是否完成的操作手冊。實作細節見 [tasks.md](tasks.md)。

## 前置條件

- 001～005 已完成，`npm install` 完成。
- Google 設定依 002 的 quickstart：環境變數 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`GOOGLE_API_KEY`、`GOOGLE_APP_ID` 由使用者自行設定（不讀取、不印出 `.env`）。
- 老師的雲端硬碟中有：題組＋單題範本的副本（可編輯）、單題範本的副本（可編輯）、003 驗證用的變形試算表、一份只有檢視權限的試算表。

## 自動化測試

```bash
npm test -w server -- results
npm test -w frontend -- ServerResultService
npm run test:e2e -w frontend -- results
```

不需要網路與 Google 憑證（research RD-11）。

## 手動驗證情境

`npm run dev`，開 1 個老師分頁與 3 個學生分頁（第 1、2、3 組）。匯入題組＋單題範本的副本，建立 3 組的活動，跑完 4 題：

- 第 1 題：第 2 組先送出被拒絕，第 1 組被接受。
- 第 2 題：第 3 組被接受，答案為 `=1+1`。
- 第 3 題：有組別送出，但都被拒絕。
- 第 4 題（題組）：沒有人送出。

| # | 操作 | 預期結果 | 對應 |
| --- | --- | --- | --- |
| 1 | 第 1 題結束時看第 2 組學生分頁 | 1 秒內出現成功組別第 1 組與答案、送出組數，以及本組送出的答案（不顯示順位）；看不到其他組的答案；題目進度只有第 1 題 | AC-01、AC-02、AC-10、SC-005 |
| 2 | 第 2 題進行中，在學生分頁的瀏覽器主控台送出 `result:question` 第 2 題 | 回「這一題還沒結束，結果尚未公布」 | AC-05 |
| 3 | 第 3、4 題結束時看老師與學生分頁 | 第 3 題「沒有組別搶答成功」，第 4 題「沒有組別送出」 | AC-03、AC-04 |
| 4 | 活動結束後看學生分頁 | 每題所有送出的順位、組別、答案與判定，以及本組搶到的題數 | AC-07 |
| 5 | 活動結束後看老師結果頁 | 每題成功組別、送出組數、每題所有送出的順位與判定、比第一名（最早送出的組別）慢的秒數、各組搶到的題數 | AC-08、AC-30 |
| 6 | 先在試算表第 2 題的填空格手動打字，再按「寫回 Google Sheets」 | 確認視窗文字為「這些填空格原本的內容會被覆蓋。」，沒有提到備份 | AC-11 |
| 7 | 按「寫回」，打開試算表（寫回預覽只顯示答案，不含小題標記） | 多一個「原名-備份-YYYYMMDD-HHmm」工作表，內容與寫回前相同；第 1、2 題填空格為成功答案，`=1+1` 顯示為文字；第 3、4 題填空格不變；題組範本的答案寫在 H 欄（只有答案），G 欄的「（1）」等標記不變 | AC-12～AC-16、SC-001、SC-008 |
| 8 | 用版本記錄比對寫回前後 | 只有第 1、2 題的填空格不同 | AC-15、SC-002 |
| 9 | 同一分鐘內再寫回一次 | 新備份名稱加「-2」；填空格內容與上一次相同 | AC-17、AC-19 |
| 10 | 在試算表第 2 題上方插入一列後寫回 | 失敗，指出第 2 題；沒有新增備份、沒有格子被改 | AC-21、SC-007 |
| 11 | 改用只能檢視的試算表跑一輪後寫回 | 「沒有編輯權限，無法寫回…」，試算表沒被改 | AC-22 |
| 12 | 把學習單工作表改名後寫回 | 「找不到學習單…」 | AC-23 |
| 13 | 在 Google 帳號的第三方存取中移除本系統後寫回 | 「Google 授權已失效…」，試算表沒被改；重新登入後進入挑選學習單頁（001 D21 完成前的暫時限制），伺服器的 `result:all` 仍回傳結果 | AC-24 |
| 14 | 寫回時關掉網路 | 15 秒內顯示連不上 Google 的原因；恢復後重試成功，結果相同 | AC-25、AC-26 |
| 15 | 用變形試算表跑一輪後寫回 | 答案寫在正確的填空格，不需修改程式 | SC-003 |
| 16 | 200 題的學習單，用 005 的壓力測試腳本自動跑完（每題都有一組被接受）後寫回 | 5 秒內完成 | SC-004 |
