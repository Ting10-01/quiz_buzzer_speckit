# Quickstart: 畫面與流程原型

本文件說明如何執行 001 並驗證它符合 spec。介面與資料見 [contracts/](contracts/) 與 [data-model.md](data-model.md)，這裡不重複。

## 前置需求

- Node.js 24 LTS（repo 根目錄的 `.nvmrc`）
- 第一次執行端對端測試前，安裝 Playwright 的 Chromium
- 001 不需要 Google 帳號、金鑰或 `.env`

## 安裝與啟動

在 repo 根目錄執行：

```bash
npm install
```

```bash
npx playwright install chromium
```

```bash
npm run dev
```

開啟終端機顯示的本機網址，每個頁面都應看到「模擬模式」標示。要同時展示老師與學生，開多個分頁；每個分頁的模擬狀態各自獨立，重新整理即回到首頁與「沒有活動」。

## 自動化測試

| 指令 | 內容 | 預期結果 |
| --- | --- | --- |
| `npm run typecheck` | `shared/`、`frontend/` 的 TypeScript 檢查 | 沒有錯誤 |
| `npm run lint` | ESLint，含「頁面與元件不得引用 `services/mock`」規則（原則 III） | 沒有錯誤 |
| `npm test` | Vitest：`tests/unit`、`tests/component` | 全部通過 |
| `npm run test:e2e` | Playwright：`tests/e2e` | 全部通過 |

implement 階段每完成一個 Phase，回報上述指令與結果（原則 VIII）。

## 驗證情境

每個情境對應 spec 的 User Story 與 Success Criteria；自動化測試與人工驗證都依此執行。人工驗證結果記錄在 `specs/001-ui-prototype/manual-verification.md`（日期、驗證者、情境、結果、問題）。

| 編號 | 情境 | 操作 | 預期結果 | 對應 |
| --- | --- | --- | --- | --- |
| Q1 | 選擇身分 | 首頁點「我是學生」；回首頁點「我是老師」 | 分別進入選組頁與登入頁 | US1、SC-005 |
| Q2 | 登入兩種結果 | 登入頁點「用 Google 登入」，依序選兩個模擬帳號選項 | 選「模擬老師帳號」進入挑選學習單頁並顯示帳號；選「取消」留在登入頁並顯示「已取消登入」 | US1 AC-3、AC-4 |
| Q3 | 匯入三份學習單 | 依序挑選三份模擬學習單；對「表頭錯誤範例」按「重新讀取」；關閉選擇器 | 依 M2 進入確認辨識結果頁或找不到表頭頁；關閉時留在原頁 | US2 AC-1–5 |
| Q4 | 活動設定與驗證失敗 | 調整組數；點「模擬：驗證失敗」後按「建立活動」；再按一次 | 第一次在組數欄位旁顯示「模擬：驗證失敗」；第二次進入控制台・準備中 | US2 AC-7–10、US5 AC-8 |
| Q5 | 主持與判定 | 開放每一題，接受或不接受，結束每一題 | 依「頁面與按鈕」表切換；最後一題沒有送出；結束最後一題進入結果頁 | US3 AC-1–9 |
| Q6 | 寫回 | 以兩份可辨識的學習單各走一次到寫回 | 「題組＋單題範本」寫回成功並顯示格數；「單題範本」寫回失敗並顯示原因 | US3 AC-10–12 |
| Q7 | 學生被接受與被拒絕 | 學生加入組別，推進到作答，送出後分別點「模擬：接受」「模擬：不接受」，被拒絕後重送 | 接受時顯示已接受；不接受時回到作答頁被拒絕狀態並保留答案；重送進入等待判定 | US4、SC-006 |
| Q8 | 學生走完所有階段 | 持續點「模擬：推進到下一個階段」直到已結束，再點一次 | 依 M7 切換到本題結果與全部結果頁；已結束後不再改變 | US4、US5 AC-4 |
| Q9 | 模擬模式涵蓋全部流程 | 依畫面流程圖逐一走過每個狀態與箭頭 | 每個狀態都到達、每條箭頭都觸發；每頁都有「模擬模式」標示；控制只出現在 FR-061 指定的頁面 | US5、SC-001–003 |
| Q10 | 不出現的元素 | 檢視所有頁面 | spec「相對於設計稿的調整」移除的元素一個都不出現；學生作答與等待判定時看不到其他組作答 | SC-004、SC-007 |
| Q12 | 非預期錯誤 | 在 FR-061 列出的每個頁面點「模擬：非預期錯誤」（控制列顯示「已設定」提示），再點一個會呼叫介面的按鈕；接著再點一次 | 第一次停留在原頁，共通錯誤訊息區顯示「模擬：連不上伺服器」，已輸入的內容不變（確認視窗中的按鈕會先關閉視窗）；第二次成功並清除訊息 | US5 AC-9–11；FR-009；FR-061；SC-002 |
| Q11 | 學生頁面版面 | 在桌面寬度的視窗開學生頁面 | 以手機寬度的欄位置中顯示 | spec Assumptions |
