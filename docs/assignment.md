# 作業原始需求

## 背景

某一門課的老師想在課堂規劃一個搶答活動環節，課程使用填空式學習單 (Guided Notes) 作為搶答的題目，並在活動前發給各組別填寫。活動開始後，老師先將講義收回，然後開放學生上台將答案寫在黑板上。

老師覺得這個做法太耗時間，所以他想開發一個系統來讓這個活動可以線上進行。

## 系統需求

### 核心功能

| 編號 | 需求 | 對應 spec |
| --- | --- | --- |
| R1 | 有老師與學生兩種使用者 | |
| R2 | 老師可以匯入 Guided Notes 題目（詳見 Guided Notes 格式規範） | |
| R2.1 | 題數要與 Guided Notes 一致 | |
| R2.2 | 不要求匯入題目敘述，僅需以題號表示即可 | |
| R3 | 老師可以開啟、結束搶答 | |
| R4 | 老師可以檢視搶答時的作答狀況、搶答結果 | |
| R5 | 老師可以匯出搶答成功的組別答案至原 Guided Notes | |
| R5.1 | 須將答案寫入至原本題目的填空格中 | |
| R6 | 學生可以在搶答開始後作答題目 | |
| R7 | 學生依組別為單位送出答案 | |
| R8 | 學生在搶答結束後檢視結果 | |
| R9 | 學生在搶答結束前看不到其他組別的作答狀況 | |
| R10 | 最快搶答的組別選定為搶答成功的答案 | |
| R11 | 同步所有使用者的活動階段 | |

### 額外功能

| 編號 | 需求 | 對應 spec |
| --- | --- | --- |
| E1 | 加入匯入題組（搶答時須同時送出的題目）的功能 | |
| E2 | 匯出儲存活動結果（例：題號、組別答案、搶答順位）至 csv | |
| E3 | 更公平的搶答順位機制，鼓勵還沒搶答成功的組別參與 | |
| E4 | 其他你認為能增進搶答活動品質的功能 | |

## Guided Notes 格式規範

- 以 Google Sheets 的形式儲存。
- 提供單題以及題組的範本，請自行複製使用（單題範本；題組+單題範本）。
- 可自行對範本進行修改，好方便匯入/匯出（如：在填空格加上佔位符、題目敘述註加記號）。
- 如有需求，也可以設計自己的 Guided Notes 做測試，但請一律設計為簡答題。

## 實作規定

- 請使用 AI 代理開發的模式完成此專案，無須自己撰寫程式碼。
  - 請隨時留意自己的 AI 用量，不要一開始就使用最高級的模型。
- 組（下稱大組）內成員分成兩個小組 —— OpenSpec 組與 SpecKit 組，各小組以 2 人為原則，並使用該工具的流程製作。
- 兩個小組產出的系統功能要一致，實作期間有任何改動要與另一小組討論。
- 必須實現上述系統需求中的核心功能；額外功能可以自行選擇要不要做、做哪些。
- SpecKit 組須導入 Diagram First Development（詳見附錄以及 eeclass 上的 AIDLC 簡報）。
- 創建 GitHub repo 來存放程式與文件，各小組分別建立一個 repo。
- 檢查 AI 生成的文件是否符合需求；系統除 AI 自動驗證外，亦須人工進行驗證。
- 請勿使用靜態方式匯入/出 Guided Notes（如：第一題答案指定匯出到 C19 儲存格），助教會使用另一份 Guided Notes 做測試。
- 請勿在文件、程式碼或 repo 中洩漏密碼、金鑰或任何機敏資料。
- 不必架設可供其他設備連線的伺服器，在本機端操作模擬即可。
- AI 模型選擇、系統框架、輔助套件、程式語言、介面設計、操作流程細節等皆無限制，可以自由發揮。

原則 XX：圖表生成 (Diagram Generation)
名稱：PlantUML 設計優先 (Design-First with PlantUML)

- 規格制定階段：在 speckit.specify 階段，必須使用 PlantUML 語法生成組件圖 (Component diagram)、類別圖 (Class diagram) 和時序圖 (Sequence diagram)。這些圖表檔案 (.puml) 必須儲存在 ./diagrams/ 目錄中。
- 產物生成：檔案建立後，必須使用 PlantUML CLI (java -jar plantuml.jar "./diagrams/*.puml") 將所有 .puml 檔案轉換為 PNG 圖片，且輸出的圖片必須儲存在相同的目錄中。
- 規劃階段：speckit.plan 階段必須將這些圖表作為主要藍圖，用以生成應用程式的架構與組件。
- 實作階段：在 speckit.implement 階段完成程式碼生成後，必須執行驗證步驟，以確保最終的程式碼與圖表完全一致。
