# 隱私權政策（課堂搶答系統）

課堂搶答系統是 NCU SE6005 課程期末專案，在使用者自己的電腦上執行，不提供公開的線上服務。

## 存取的 Google 資料

老師以 Google 帳號登入時，系統只要求下列權限：

| 權限 | 用途 |
| --- | --- |
| 電子郵件地址（`email`、`openid`） | 辨識目前登入的老師，並在頁面上顯示帳號 |
| 老師透過本系統挑選的雲端硬碟檔案（`drive.file`） | 讀取老師在 Google 檔案選擇器中挑選的學習單試算表；活動結束後，把搶答成功的答案寫回該試算表的填空格，寫回前先在同一份試算表建立備份工作表 |

系統無法看到老師沒有透過檔案選擇器挑選的任何檔案。

## 資料存放與分享

- Google 授權只存放在執行系統那台電腦的伺服器記憶體中，伺服器停止時即消失，不寫入檔案，也不上傳到 GitHub 或其他地方。
- 老師的登入憑證只存放在老師自己的瀏覽器分頁中，關閉分頁即消失。
- 學生不需要登入，系統不收集學生的個人資料。
- 系統不會把任何資料傳送或分享給第三方；除了 Google API 之外，不連線到其他外部服務。

## 撤銷授權

可隨時到 Google 帳戶的「[第三方應用程式和服務](https://myaccount.google.com/connections)」移除「課堂搶答系統」的存取權。
